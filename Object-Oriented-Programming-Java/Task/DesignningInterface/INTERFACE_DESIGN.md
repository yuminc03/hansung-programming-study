# 🎮 플레이어 캐릭터 인터페이스 설계 설명서 (INTERFACE_DESIGN)

본 문서는 플레이어 캐릭터 시스템을 유연하고 확장 가능하게 설계하기 위해 정의한 인터페이스 설계 내용을 담고 있습니다.

---

## 1. ❓ 왜 만들었나? (설계 배경 및 목적)

*   **역할 분리 원칙 (Interface Segregation Principle, ISP) 준수**: 
    캐릭터가 가져야 할 책임을 하나의 거대한 클래스나 인터페이스에 몰아넣지 않고, **이동(`Movable`)**, **공격(`Attackable`)**, **캐릭터 기본 관리(`PlayableCharacter`)** 단위로 역할을 명확히 쪼갰습니다. 이로써 이동만 가능한 객체(예: 탈것, NPC)나 공격만 가능한 객체(예: 고정 포탑)를 설계할 때도 불필요한 메서드를 억지로 구현할 필요 없이 유연한 구조를 유지할 수 있습니다.
*   **느슨한 결합 (Loose Coupling) 지향**:
    구체적인 직업 클래스(`Warrior`, `Wizard`, `Archer`)에 의존하지 않고, 추상화된 인터페이스 규약만으로 캐릭터를 생성 및 동작시킬 수 있도록 하여 코드 간 결합도를 낮추고 시스템의 유지보수성을 극대화했습니다.
*   **행동 중심의 마나(MP) 기반 동작 확인**:
    각 캐릭터가 고유한 공격이나 스킬을 수행할 때 에너지(마나)를 소모하는 과정을 설계하여, 내부 필드의 상태가 행동 메서드 호출에 따라 어떻게 변하는지 일관되게 확인하기 위해 구축되었습니다.

---

## 2. 🗂️ 어떤 속성으로 구성했나? (클래스 구성 속성)

각 직업군 클래스(`Warrior`, `Wizard`, `Archer`)는 공통적으로 다음 3가지의 내부 속성(멤버 변수)을 가지며, 정보 은닉을 위해 `private`으로 캡슐화되어 있습니다.

| 속성명 | 데이터 타입 | 설명 |
| :--- | :--- | :--- |
| `name` | `String` | 캐릭터의 고유 이름을 저장하는 속성 |
| `hp` | `int` | 캐릭터가 외부로부터 공격받았을 때 소모/변화하는 체력(HP) 수치를 저장하는 속성 |
| `mp` | `int` | 캐릭터가 공격이나 스킬을 사용할 때 소모/변화하는 마나(MP) 수치를 저장하는 속성 |

---

## 3. 🛠️ 어떤 메서드로 구성했나? (인터페이스 핵심 메서드)

인터페이스에 정의된 규약에 따라 구현체들은 다음의 핵심 메서드들을 강제 및 오버라이딩하여 동작을 정의합니다.

### 🏃 Movable 인터페이스
*   **`void move()`**
    *   캐릭터가 맵 상에서 이동하는 행동을 콘솔에 출력합니다.
    *   직업의 개성에 따라 다른 이동 로그(예: 전사 - 묵직한 보행, 마법사 - 순간이동, 궁수 - 질주)가 발생합니다.

### ⚔️ Attackable 인터페이스
*   **`void attack()`**
    *   캐릭터가 일반 공격을 시도하는 행동입니다.
    *   공격 시 자신의 마나(MP)를 소모(전사 -10, 마법사 -15, 궁수 -8)하고 남은 MP 정보를 출력하여 내부 상태의 변화를 검증합니다.

### 🛡️ PlayableCharacter 인터페이스
*   **`void useSkill()`**
    *   각 캐릭터의 전용 액티브 스킬(예: 휠윈드, 블리자드, 멀티플 샷)을 시전하는 특화 행동 메서드입니다.
*   **`void showStatus()`**
    *   캐릭터의 이름, 직업명, 현재 남은 체력(HP) 및 마나(MP) 등의 고유 상태 정보를 한눈에 볼 수 있도록 출력하는 모니터링 메서드입니다.
*   **`void takeDamage(int damage)`**
    *   외부로부터 물리적/마법적 충격을 받았을 때, 전달받은 `damage`만큼 체력(HP)을 감소시키는 처리 메서드입니다.
    *   연산 시 체력이 0 이하의 음수 수치로 떨어지는 것을 차단하기 위해 `Math.max(0, ...)` 안전 장치가 기본 적용됩니다.
*   **`String getName()`**
    *   캡슐화된 캐릭터의 이름(`name`) 속성을 안전하게 반환받기 위한 표준 Getter 메서드입니다.
