# 프로젝트 1. 폴더 대청소 — 파일 자동 정리

**한 줄 목표**: 어질러진 폴더(45개 파일)를 분류·이름규칙·중복점검까지 자동 정리하고, **파일을 잃어버리지 않았는지 검산**한다.

**이런 업무에 씁니다**: 다운로드·바탕화면·공유폴더가 늘 어질러져 있는 모든 분 (2026년 반복업무 자동화 수요 1위)

| 항목 | 내용 |
|---|---|
| 입력 (자료/) | 어질러진폴더 — 회의록·보고서 버전들·스크린샷·임시파일·중복 등 45개 |
| 결과물 (결과물/) | ① 정리된폴더(분류 복사본) ② 정리로그.md |


## 진행 방법
`실습프롬프트.txt` 순서대로: 인벤토리(탐색) → 정리 규칙(계획) → 복사 정리(구현) → 개수 검산(검증).

## 확인 포인트 (셀프 채점)
- [ ] 원본 폴더(어질러진폴더)는 그대로인가 — 파일 45개, 수정·삭제 없음
- [ ] 정리된폴더에도 45개가 전부 있는가 (구버전·분류 보류 포함)
- [ ] 중복 후보(내용이 같은 파일 3쌍)가 **삭제되지 않고 목록으로** 보고됐는가
- [ ] 버전 파일(v1/v2/최종/진짜최종)에서 최신본이 상위에 있는가
- [ ] 정리로그만 보고 "어떤 파일이 어디로 갔는지" 추적되는가

## 핵심 메시지
"정리는 AI가, 삭제 결정은 사람이. 그리고 정리 후엔 반드시 개수 검산."
