【프로젝트 1】 폴더 대청소 — 파일 자동 정리 

기본 원칙: 한 번에 다 시키지 않고 탐색 → 계획 → 구현 → 검증 순서로.
모든 프롬프트는 업무지시서 6요소(목표/자료/형식/저장/주의/확인)로 씁니다.

==================================================
STEP 0. [탐색] 폴더 인벤토리 
==================================================

목표: 프로젝트1_폴더대청소의 자료/어질러진폴더 안에 어떤 파일이
      몇 개나 있는지 종류별로 파악
자료: 자료/어질러진폴더 (안의 모든 파일)
주의: 아직 아무것도 만들거나 옮기지 마. 파일 개수와
      종류별 분포, 눈에 띄는 문제(중복 의심, 버전 중복,
      이름만으로 내용을 알 수 없는 파일)만 보고해줘.

==================================================
STEP 1. [계획] 정리 규칙 세우기
==================================================

목표: 이 폴더를 정리할 규칙(분류 체계 + 이름 규칙) 수립
자료: 방금 탐색한 인벤토리 결과
형식: ① 분류 폴더 구조(예: 회의록/보고서/데이터/이미지/문서/기타)
      ② 파일명 규칙(예: 날짜_내용 형식)
      ③ 중복·버전 파일 처리 방침
주의: 계획만 세우고 아직 실행하지 마. 원본 삭제는 어떤 경우에도
      계획에 넣지 마 — 중복도 지우지 말고 "중복 후보 목록"으로만.
확인: 45개 파일이 모두 어느 분류에 들어가는지 빠짐없이 배정됐는지.

==================================================
STEP 2. [구현] 복사 정리 실행
==================================================

목표: 승인한 규칙대로 어질러진폴더를 정리
자료: 자료/어질러진폴더 (원본)
형식: 결과물/정리된폴더 아래에 분류 폴더를 만들고,
      원본 파일을 규칙에 맞는 이름으로 **복사**해서 배치.
      버전 파일(v1/v2/최종/진짜최종)은 최신본만 상위에,
      나머지는 구버전 하위폴더로.
저장: 정리 내역 전체를 결과물/정리로그.md 로 저장
      (원본 이름 → 새 위치/새 이름 표, 중복 후보 목록 포함)
주의: 원본(자료/어질러진폴더)은 절대 수정·이동·삭제하지 말 것.
      복사만 한다. 내용을 알 수 없는 파일(무제.txt 등)은
      임의로 판단하지 말고 "분류 보류" 폴더로.
확인: 원본 45개 파일이 정리된폴더에 전부 존재하는지 개수 검산.

==================================================
STEP 3. [검증] 개수 검산 + 누락 점검 
==================================================

목표: 정리 과정에서 잃어버린 파일이 없는지 검증
자료: 자료/어질러진폴더 (원본) / 결과물/정리된폴더 / 결과물/정리로그.md
형식: 원본 파일 수 vs 정리 후 파일 수 대조표 + 누락/중복 배치 목록
저장: 검증 결과를 결과물/정리로그.md 맨 아래에 "검증" 부분으로 추가
주의: 개수가 안 맞으면 어떤 파일이 빠졌는지 이름까지 찾아서 보완해줘.
확인: 원본 45개 = 정리 후 45개(구버전·분류 보류 포함)로 일치하는가.

==================================================
마무리 확인:
1. 원본 폴더는 그대로인가 (파일 수·내용 변화 없음)
2. 정리된폴더에서 원하는 파일을 10초 안에 찾을 수 있는가
3. 정리로그만 보고도 "어떤 파일이 어디로 갔는지" 추적되는가
(→ 실무 적용: 내 다운로드 폴더에 같은 프롬프트를 그대로 쓰면 됩니다.
   단, 실무에서도 먼저 복사로 연습한 뒤 이동 정리로 넘어가세요.)
