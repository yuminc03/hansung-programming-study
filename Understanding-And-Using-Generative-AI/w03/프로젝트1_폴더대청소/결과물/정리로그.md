## 7. 가정과 확인이 필요한 사항

1. 매출보고서의 버전 순서(v1 → v2 → 최종 → 진짜최종)는 파일 이름과 본문 문구("이것이 실제 최종")에서 추정했다. 순서가 다르면 v3·v4 번호를 바꿔야 한다.
2. `출장보고_대전_0610.txt`는 내용에 연도가 없다. 다른 회의록이 2026년이라 2026년으로 가정했다.
3. 이미지·PDF·xlsx·pptx·zip 22개는 더미 파일이라 실제 내용은 확인하지 못했다. 이름의 날짜와 표기만으로 정리했다.
4. `사진백업_0601.zip`, `폰트모음.zip`은 압축을 풀지 않았다. 안의 파일이 정리된 이미지와 겹치는지는 모른다.
5. `6월매출_임시.csv`, `고객명단_백업.csv`는 내용이 헤더뿐이다. 이름은 "임시"·"백업"이지만 실제 용도는 확인하지 못했다.
6. `99_분류보류/`의 `메모장.txt`(전화번호 형식)와 `새 텍스트 문서 (2).txt`(와이파이 이름)는 민감 정보일 수 있어 사람이 용도를 정하기를 권한다.
7. 정리본에는 원본을 지우는 단계가 없다. 원본 폴더 `자료/어질러진폴더/`는 그대로이고, 중복 후보와 구버전을 지울지는 사람이 결정한다.
