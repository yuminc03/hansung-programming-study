# 프로젝트 2. 회의록 → 요약 → 보고서 → 공유메일

**한 줄 목표**: 회의록 파일 1개로 "팀장 보고용 요약 → 업무보고서 → 팀 공유메일" 3종을 만든다.

**이런 업무에 씁니다**: 회의 끝날 때마다 정리해서 보고하고 공유하는 일이 반복되는 분 (문서 요약·작성 = AI 효과 체감 1위)

| 항목 | 내용 |
|---|---|
| 입력 (자료/) | 회의록.txt — 한빛리빙 주간 운영회의 |
| 결과물 (결과물/) | ① 회의록_요약.md → ② 업무보고서_초안.md → ③ 공유메일_초안.md |
| 배우는 것 | "AI 결과물이 다음 작업의 재료가 된다" + 상대 날짜 환산 |
| 사용 강의 | 17~19강 |
| 선행 조건 | 없음 |
| 소요 시간 | 약 45분 |

## 진행 방법
`실습프롬프트.txt` 순서대로. 모든 프롬프트가 6요소(목표/자료/형식/저장/주의/확인)입니다.

## 확인 포인트 (셀프 채점)
- [ ] 결과물/ 폴더에 파일 3개가 생겼는가
- [ ] 담당자 4명(최주임·정사원·박팀장·김상무)과 기한이 원본 회의록과 일치하는가
- [ ] "이번 주 목요일" 같은 상대 날짜가 실제 날짜로 환산됐는가
- [ ] 보고서(5단 구조)와 공유메일(본문 10줄 내외)의 **형식이 서로 다른가** — "같은 재료, 다른 형식"
- [ ] 회의록에 없는 내용을 지어내지 않았는가
