================================================================
고객 문의 자동 배정 대시보드 — 바이브코딩 프롬프트
================================================================

이 폴더에서 AI 코딩 도구(Claude Code · Cursor · Gemini CLI 중 하나)를 열고,
아래 STEP을 하나씩 붙여 넣습니다. 한 번에 전부 넣지 않습니다.
( ) 안은 바꿔 넣는 자리입니다. API 키는 필요 없습니다.


================================================================
STEP 0  [탐색]
================================================================

이 폴더의 01_고객문의_자동배정_토큰화_임베딩_의미공간.ipynb를 읽어봐.
문의 문장을 임베딩으로 바꾸고, FAQ와 코사인 유사도를 재서
가장 비슷한 FAQ의 담당팀을 붙이는 흐름을 이해해줘.
유사도가 기준값(0.55)보다 낮으면 '담당자 확인'으로 넘기는 이유도 설명해줘.
아직 아무것도 만들지 마.


================================================================
STEP 1  [계획]
================================================================

이해한 코드를 바탕으로 "고객 문의 자동 배정 대시보드"를 만들 계획을 세워줘.

- 기준 자료: 노트북 안의 FAQ 12건(질문·답변·담당팀)을 그대로 사용
- 입력: 화면에서 고객 문의를 한 줄 입력하거나, 여러 줄을 한 번에 붙여 넣기
- 처리: 노트북과 같은 임베딩 모델(BAAI/bge-m3, CPU)과 코사인 유사도
- 출력: 문의마다 가장 비슷한 FAQ 3개와 유사도, 배정 담당팀
- 기준값(0.55) 미만이면 '담당자 확인'으로 표시
- 모델은 처음 한 번만 불러오고 다시 쓰도록(캐시) 만들어줘

계획만 보여주고 코드는 아직 만들지 마.


================================================================
STEP 2  [구현]
================================================================

계획대로 app.py 한 파일로 구현해서 브라우저에서 바로 쓸 수 있는
Streamlit 대시보드로 만들어줘.

화면 구성
  1) 왼쪽     기준값 슬라이더(0.3~0.9, 기본 0.55) · FAQ 12건 표
  2) 맨 위    문의 입력창(여러 줄 가능) · 배정 실행 버튼
  3) 가운데   배정 결과표 (문의 · 배정 담당팀 · 유사도 · 가장 비슷한 FAQ)
              '담당자 확인'은 빨간색으로 표시
  4) 아래     문의 하나를 고르면 유사도 상위 3개 FAQ를 가로 막대로 표시
  5) 맨 아래  팀별 배정 건수 표 · 결과 CSV 다운로드 버튼

조건
  - 실행 명령: streamlit run app.py
  - 모델 로딩은 st.cache_resource로 한 번만
  - 입력이 비어 있으면 안내 문구만 보여주고 멈춰줘

마지막에 실행 방법을 한 줄로 알려줘.


================================================================
STEP 3  [검증]
================================================================

직접 실행해서 아래를 확인하고 결과를 알려줘.

  1) streamlit run app.py 로 오류 없이 화면이 뜨는가
  2) "택배가 아직 안 왔어요" → 배송팀으로 배정되는가
  3) "채용 공고는 어디서 보나요?" → '담당자 확인'으로 빨갛게 표시되는가
     반드시 실패 사례로 시험해줘
  4) 기준값 슬라이더를 0.9로 올리면 대부분이 '담당자 확인'으로 바뀌는가
  5) 빈 입력으로 실행해도 프로그램이 멈추지 않는가

(사람 검증: 배정 결과가 상식적으로 맞는지 5건을 직접 읽어 확인)

핵심 메시지: "기계는 비슷한 것을 찾고, 확신 없는 판단은 사람에게 넘긴다."


================================================================
STEP 4  [응용]
================================================================

지금 만든 프로그램에서 FAQ 표만 바꿔서
"( 사내 IT 헬프데스크 문의 배정 )"으로 고쳐줘.

  ↑ 아래에서 하나 골라 바꿔 쓴다
     ( 사내 IT 헬프데스크 문의 배정 )     정보시스템

     ( 민원 부서 자동 분류 )              공공 · 행정
     ( 부동산 중개 문의 담당자 배정 )     영업

FAQ 12건을 그 업무에 맞게 새로 쓰고, 화면 구성은 그대로 둬.
바꾼 뒤 다시 실행해서 화면이 정상인지 확인해줘.


================================================================
STEP 5  [기록]
================================================================

지금까지 만든 것을 README.md로 정리해줘.

- 어떤 업무를 자동화했는가 (한 문장)

- 기준값이 왜 필요한가, 실제로 무엇이 걸러졌는가
- 이 방식이 잡아내지 못하는 경우는 무엇인가

실행 화면을 캡처해서 넣을 자리도 표시해줘.
취업 포트폴리오에 그대로 넣을 수 있는 수준으로 작성해줘.
