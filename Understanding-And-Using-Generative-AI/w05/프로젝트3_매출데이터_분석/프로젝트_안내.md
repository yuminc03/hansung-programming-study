# 프로젝트 3. 매출데이터 분석 + 숫자 검증 ★이 강의에서 가장 중요

**한 줄 목표**: 매출 CSV(124행)를 분석 보고서로 만들고, **AI가 만든 숫자를 원본과 직접 대조**한다.

**이런 업무에 씁니다**: 매출·실적 엑셀 자료를 정리해 보고해야 하는 분 (데이터 분석 = 2026 학습 수요 2위)

| 항목 | 내용 |
|---|---|
| 입력 (자료/) | 매출자료.csv, 매출자료.xlsx — 2026년 6월, 상품 6종, 124행 |
| 결과물 (결과물/) | ① 매출분석_보고서.md → ② 매출검증_결과.md |
| 배우는 것 | 데이터 분석 지시법 + **"AI 숫자는 반드시 검증한다"는 습관** |
| 사용 강의 | 20~21강 |
| 선행 조건 | 없음 |
| 소요 시간 | 약 40분 |

## 진행 방법
`실습프롬프트.txt` 순서대로: 탐색 → 분석 보고서 → 숫자 검증 → 엑셀 SUM 직접 대조(사람이).

## 확인 포인트 (셀프 채점 — 정답 숫자)
- [ ] 총매출 **11,406,000원**, 총 124행, 기간 2026-06-01~30
- [ ] 매출 1위: 스테인리스 텀블러 500ml (3,766,800원 / 292개)
- [ ] 매출 2위: 극세사 청소포 리필 30매 (2,504,700원 / 363개)
- [ ] 최하위: 대나무 도마 세트 (1,150,500원 / 59개)
- [ ] 보고서에 **계산 근거**가 남아 있는가
- [ ] 매출자료.xlsx에서 =SUM()으로 구한 값과 AI 보고서의 총매출이 일치하는가

## 핵심 메시지
"AI가 만든 숫자는 반드시 한 번은 원본과 대조한다.
검증을 통과한 결과물만 보고서에 쓴다."
