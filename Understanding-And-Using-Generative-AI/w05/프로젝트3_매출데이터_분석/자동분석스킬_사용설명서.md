# 📊 판매 데이터 자동 분석 스킬 사용설명서

## 개요

이 스킬은 CSV 형식의 판매 데이터를 자동으로 분석하여:
- 📄 **매출 분석 보고서** 자동 생성
- 🔐 **검증 보고서** 자동 생성
- ✅ **데이터 무결성** 자동 확인

하는 재사용 가능한 자동화 도구입니다.

---

## 시스템 요구사항

### Python 버전 (권장 - 더 안정적)
- **Python 3.6 이상** 설치 필요
- 추가 패키지 불필요 (표준 라이브러리만 사용)
- **문자 인코딩 완벽 지원**

### PowerShell 버전
- **PowerShell 5.1 이상** (Windows 10/11 기본 포함)
- 한글 인코딩 이슈 가능성

## 입력 데이터 형식

### 필수 CSV 구조
```
날짜,상품명,카테고리,수량,단가,매출액
2026-06-01,상품A,카테고리A,10,10000,100000
2026-06-01,상품B,카테고리B,5,20000,100000
```

### 필수 컬럼
| 컬럼명 | 타입 | 설명 | 예시 |
|--------|------|------|------|
| 날짜 | YYYY-MM-DD | 거래 날짜 | 2026-06-01 |
| 상품명 | 문자열 | 상품 이름 | 스테인리스 텀블러 500ml |
| 카테고리 | 문자열 | 상품 분류 | 주방용품 |
| 수량 | 정수 | 판매 수량 | 14 |
| 단가 | 정수 | 상품 단가(원) | 12900 |
| 매출액 | 정수 | 판매액(수량×단가) | 180600 |

## 사용 방법

### 1️⃣ Python 버전 사용 (권장)

#### 기본 실행
```bash
python 자동분석스킬.py --data "자료/매출자료.csv"
```

#### 옵션이 포함된 실행
```bash
python 자동분석스킬.py \
  --data "자료/매출자료.csv" \
  --output "결과물" \
  --prefix "6월"
```

#### 옵션 설명
| 옵션 | 약칭 | 설명 | 기본값 |
|------|------|------|--------|
| `--data` | `-d` | CSV 파일 경로 **(필수)** | - |
| `--output` | `-o` | 결과 저장 디렉토리 | 입력 파일 디렉토리 |
| `--prefix` | `-p` | 생성할 파일명 접두어 | `매출분석` |

#### 실행 예제
```bash
# 기본 사용법
python 자동분석스킬.py -d "매출자료.csv"

# 출력 디렉토리 지정
python 자동분석스킬.py -d "data.csv" -o "reports"

# 파일명 접두어 커스터마이징
python 자동분석스킬.py -d "2026년6월.csv" -p "6월분석"
```

## 출력 파일

### 1. 매출 분석 보고서 (`{prefix}_보고서.md`)

자동으로 생성되는 항목:
- ✅ **요약 통계** - 총매출, 판매수량, 거래건수, 상품종류
- ✅ **총매출** - 분석 기간 총매출액
- ✅ **상품별 순위** - 매출액 기준 정렬된 상품별 판매 현황
- ✅ **상위/하위 상품** - 최고/최저 판매 상품 분석
- ✅ **개선 포인트** - 3가지 실무 개선 방안

### 2. 검증 보고서 (`{prefix}_검증_결과.md`)

자동으로 확인되는 항목:
- ✅ **총매출 검증** - 보고서의 총매출이 정확한가?
- ✅ **상품별 판매액 검증** - 각 상품의 판매액이 맞는가?
- ✅ **수량 검증** - 판매 수량이 정확한가?
- ✅ **거래 건수 검증** - 거래 건수가 정확한가?
- ✅ **100% 일치 확인** - 모든 수치가 원본 데이터와 일치

## 문제 해결

### Q1: "파일을 찾을 수 없습니다" 오류
**해결책:**
- CSV 파일의 정확한 경로를 확인하세요
- 상대 경로 대신 절대 경로를 사용하세요
```bash
# 잘못된 예
python 자동분석스킬.py --data "매출자료.csv"

# 올바른 예
python 자동분석스킬.py --data "D:\data\매출자료.csv"
```

### Q2: CSV 파일이 읽히지 않음
**해결책:**
- CSV 파일이 **UTF-8** 또는 **UTF-8 with BOM** 인코딩인지 확인
- Excel에서 "CSV (쉼표로 구분)" 형식으로 저장하세요
- 한글 인코딩 문제 시 Python 버전 사용 권장

### Q3: 결과 파일이 생성되지 않음
**해결책:**
- 출력 디렉토리의 쓰기 권한 확인
- 디렉토리가 없으면 자동으로 생성됩니다
- 기존 파일이 있으면 덮어씁니다

## 검증 항목 상세

| 검증 항목 | 설명 | 확인 방법 |

## 자주 묻는 질문 (FAQ)

### Q: 매달 자동으로 실행할 수 있나요?
**A:** 네! Windows 작업 스케줄러나 Linux cron job을 사용하면 자동화할 수 있습니다.

### Q: 분석 결과를 Excel로 변환할 수 있나요?
**A:** Markdown 파일을 복사해서 다른 도구(Excel, Word 등)에 붙여넣기할 수 있습니다.

### Q: 여러 분류(카테고리)별로 따로 분석 가능한가요?
**A:** 현재는 전체 데이터를 분석합니다. 카테고리별로 필터링한 CSV를 별도로 만들어 분석하면 됩니다.

### Q: 개선 포인트는 커스터마이징할 수 있나요?
**A:** 현재는 자동 생성되며, 필요시 생성 후 Markdown 파일을 수동으로 편집할 수 있습니다.
