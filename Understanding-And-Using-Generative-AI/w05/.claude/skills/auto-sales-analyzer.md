# 판매 데이터 자동 분석 스킬

CSV 형식의 판매 데이터를 자동으로 분석하여 보고서와 검증 결과를 생성합니다.

## 사용 방법

```
/자동분석스킬 --data "자료/매출자료.csv"
/자동분석스킬 --data "자료/매출자료.csv" --output "결과물" --prefix "6월"
```

## 입력 파일 형식

CSV 파일이 다음 구조를 가져야 합니다:

```
날짜,상품명,카테고리,수량,단가,매출액
2026-06-01,상품A,카테고리A,10,10000,100000
```

### 필수 컬럼
- **날짜**: YYYY-MM-DD 형식
- **상품명**: 상품 이름
- **카테고리**: 상품 분류
- **수량**: 판매 수량 (정수)
- **단가**: 상품 단가 (정수, 원화)
- **매출액**: 판매액 (수량 × 단가)

## 생성되는 출력

### 1. 매출 분석 보고서 ({prefix}_보고서.md)
- 📊 요약 통계 (총매출, 판매수량, 거래건수)
- 💰 총매출액
- 📈 상품별 매출 순위 (매출액 기준)
- 🏆 상위/하위 상품 분석
- 💡 개선 포인트 (3가지)

### 2. 검증 보고서 ({prefix}_검증_결과.md)
- ✅ 총매출 검증
- ✅ 상품별 판매액 검증
- ✅ 판매수량 검증
- ✅ 거래건수 검증
- ✅ 100% 일치 확인

## 옵션

| 옵션 | 약칭 | 설명 | 기본값 |
|------|------|------|--------|
| --data | -d | CSV 파일 경로 (필수) | - |
| --output | -o | 결과 저장 디렉토리 | 입력 파일 디렉토리 |
| --prefix | -p | 생성할 파일명 접두어 | 매출분석 |

## 사용 예제

### 기본 사용법
```
/자동분석스킬 --data "자료/매출자료.csv"
```

### 출력 디렉토리 지정
```
/자동분석스킬 --data "data/sales.csv" --output "reports"
```

### 파일명 커스터마이징
```
/자동분석스킬 --data "2026_06.csv" --prefix "6월분석"
```

## 주요 기능

✅ **자동 분석** - CSV 파일을 읽어 자동으로 분석  
✅ **보고서 생성** - 마크다운 형식의 전문적인 보고서 생성  
✅ **자동 검증** - 모든 계산 수치를 자동으로 검증  
✅ **한글 지원** - UTF-8 완벽 지원  
✅ **배치 처리** - 여러 파일을 순차적으로 분석 가능

## 시스템 요구사항

- **Python 3.6 이상** (Python 버전 사용 시)
- **PowerShell 5.1 이상** (PowerShell 버전 사용 시)
- CSV 파일은 UTF-8 또는 UTF-8 with BOM 인코딩

## 주의사항

- 입력 CSV 파일의 컬럼명이 정확히 "날짜,상품명,카테고리,수량,단가,매출액"이어야 합니다
- 숫자 컬럼(수량, 단가, 매출액)은 정수여야 합니다
- 날짜는 YYYY-MM-DD 형식이어야 합니다
