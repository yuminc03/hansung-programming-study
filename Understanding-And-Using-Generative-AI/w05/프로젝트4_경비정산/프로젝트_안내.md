# 프로젝트 4. 영수증 → 경비정산표

**한 줄 목표**: 영수증 30건을 분류·합산해 경비정산표를 만들되, **읽을 수 없는 항목을 AI가 지어내지 못하게** 한다.

**이런 업무에 씁니다**: 월말마다 영수증·증빙을 모아 정산하는 분 (재무 백오피스 = 2026 기업 AI 최다 도입 영역)

| 항목 | 내용 |
|---|---|
| 입력 (자료/) | 영수증모음.txt — 2026년 6월 법인카드 30건, **판독 불가 2건 포함** |
| 결과물 (결과물/) | 경비정산표.md (내역 표 + 분류별 합계 + 확인 필요 목록 + 검증) |
| 배우는 것 | 분류 기준 먼저 정하기 + 판독 불가의 정직한 처리 + 합계 검산 |
| 사용 강의 | 22~23강 |
| 선행 조건 | 없음 |
| 소요 시간 | 약 40분 |

## 진행 방법
`실습프롬프트.txt` 순서대로: 탐색 → 분류 기준(계획) → 정산표(구현) → 합계 검산(검증).

## 확인 포인트 (셀프 채점 — 정답 숫자)
- [ ] 30건이 전부 표에 있는가 (누락·중복 없음)
- [ ] 총합계 **1,129,300원** (금액 판독 가능 29건 기준)
- [ ] 분류별 합계: 식비 184,400 / 교통 92,000 / 사무용품 316,600 / 접대비 375,500 / 기타 118,800 / 분류 확인 필요 42,000
- [ ] 잉크 번짐 건(06-15 다이소)이 **[금액 확인 필요]로 합계 제외**됐는가 — 임의 숫자로 채우지 않았는가 (가장 중요!)
- [ ] 사용처 불명 건(06-28, 42,000원)이 분류 [확인 필요]로 표시되고 합계에는 포함됐는가

## 핵심 메시지
"영수증 정리는 AI가, 판독 불가 판정은 정직하게, 확인은 사람이."
