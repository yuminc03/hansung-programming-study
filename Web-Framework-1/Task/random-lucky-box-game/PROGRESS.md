- `LuckyBox.js`: 박스를 열고 결과를 표시한다. 200P 미만이면 버튼을 비활성화하고 포인트 부족 안내를 보여준다.

- `App.js`: 모든 상태와 핸들러를 관리한다. 당첨 기록 id는 `useRef` 카운터로 만든다. 초기화 버튼은 닉네임, 포인트, 목록, 마지막 결과, 이용 횟수, 상세 정보를 모두 되돌린다.
- `App.css`: 카드형 레이아웃, 결과 팝 애니메이션, 비활성 버튼, 경고 문구, 목록 hover, 좁은 화면 대응 스타일을 작성했다.
- `App.test.js`: `Math.random`을 mock해서 시작 상태, 1회 열기, 중복 당첨 누적, 5회 후 비활성화, 더블클릭 삭제, 우클릭 상세, 초기화를 검증하는 테스트 7개를 작성했다. 모두 통과한다.
- `CI=true npm run build`: 경고 없이 빌드된다.
